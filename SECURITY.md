# Security and privacy reporting

Please report suspected vulnerabilities or privacy concerns privately by emailing [support@synryzen.com](mailto:support@synryzen.com).

Do not file public GitHub issues, discussions, pull requests, or comments for security vulnerabilities or privacy-sensitive reports. Include only the minimum information necessary for us to investigate, and do not send credentials, tokens, private recordings, license information, or unredacted diagnostic bundles.

We will acknowledge receipt and coordinate a private response as appropriate.
