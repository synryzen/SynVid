# SynVid Studio

Record naturally. Edit precisely. Publish anywhere.

[Download the Free Preview](https://github.com/synryzen/SynVid/releases/latest/download/SynVid.pkg) · [Product site](https://synryzen.github.io/SynVid/) · [Support](mailto:support@synryzen.com)

SynVid is a local-first macOS screen studio with movable camera PiP, independent microphone and system-audio tracks, installed VST3 voice effects, a multitrack editor, captions, markup, and creator-ready export presets.

> SynVid is currently offered as a Free Preview. Future pricing or license terms may change. This repository distributes the app; it does not contain the SynVid application source code.

## Requirements

- A Mac running macOS 26.5 or later.
- Permission to install software on the Mac.

## First install

1. Download [SynVid.pkg](https://github.com/synryzen/SynVid/releases/latest/download/SynVid.pkg).
2. Open the downloaded package and follow the macOS installer prompts.
3. Launch SynVid from Applications and grant only the capture permissions needed for your workflow.
4. In SynVid, choose **Check for Updates** to install signed updates in the app. If in-app updating is unavailable, download the current package from the [stable package URL](https://github.com/synryzen/SynVid/releases/latest/download/SynVid.pkg).

## Privacy

SynVid is local-first: recordings and editing projects stay on your Mac unless you choose to export or share them. Capture permissions are requested by macOS and can be reviewed or revoked in System Settings. Do not upload private recordings, credentials, or unredacted diagnostic material to GitHub issues; email [support@synryzen.com](mailto:support@synryzen.com) for privacy-sensitive help.

## Verify the package

Before installing, compare the package checksum published with the release against your downloaded file:

```sh
shasum -a 256 ~/Downloads/SynVid.pkg
```

Download only from the [stable package URL](https://github.com/synryzen/SynVid/releases/latest/download/SynVid.pkg) and use the checksum provided with that release.
